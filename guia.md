# Kata: FitPass Gym Network

## Description
A national fitness chain wants to create a digital platform where members can book classes, check into gyms, buy personal training sessions, and access virtual workouts.

## Users
Hundreds of thousands of gym members.

## Requirements
- Allow users to find nearby gyms.
- Allow users to book fitness classes.
- Allow users to cancel class reservations.
- Allow instructors to manage class attendance.
- Support gym check-in using mobile devices.
- Allow users to buy memberships, day passes, or training packages.
- Support national promotions.
- Support local promotions per gym.
- Notify users about class changes, cancellations, and reminders.
- Allow waitlists for full classes.
- Support virtual classes and recorded workouts.
- Integrate with payment providers.
- Integrate with door access systems at gym locations.

## Additional Context
- Each gym has different equipment, rooms, schedules, and instructors.
- Popular classes fill quickly.
- Users may book classes and not attend.
- Some memberships allow access to all gyms; others only to one location.
- The company wants to expand internationally.
- Corporate wants to collect usage analytics to optimize staffing.
